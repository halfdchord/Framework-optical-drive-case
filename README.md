# Framework optical drive case
<img width="1092" height="667" alt="image2" src="https://github.com/user-attachments/assets/6a5a52fa-bb79-42d0-a8ce-69478731beb1" />

A basic bottom case for the Framework Laptop 16 mainboard case that adds in a strange feature, a relic of the old times if you will: a slot for an Optical drive.

I made this project while trying to make an alternative bottom shell for the Framework laptop 16 that had a slot for a DVD drive, but accidentally made this. I cobbled this together in TinkerCAD (because my PC can't run real CAD software), and didn't realize that the model I was using wasn't for the actual laptop somehow. And thus, this was born. If I can get my PC to run a real CAD software, even barely, I'll try again to make an actual DVD-drive-included case for the Framework 16.

It should be compatible with the 3D-printable case's top and "screws" for the Framework 16 mainboard. Could I borrow a couple thousand dollars please?
